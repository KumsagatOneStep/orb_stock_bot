# NEXUS-7: Детектив Кода

> Интерактивный Linux-квест для начинающих DevOps-инженеров в киберпанк-сеттинге

---

## О проекте

**2089 год. Нео-Алматы.** Ты — Kira-7, системный детектив-фрилансер. Корпорация NexusTech нанимает тебя расследовать инциденты на своих серверах: утечки, саботаж, сбои. Каждый звонок — новое дело.

Квест учит базовым Linux-командам через нарративные расследования. Никакого GUI — только терминал.

---

## Требования

- macOS или Linux
- `bash`
- `python3`

## Структура квеста

| Дело | Название | Навыки | Время |
|------|----------|--------|-------|
| #001 | Призрачные Файлы | `find`, `cp`, `mv`, `chmod` | ~15 мин |
| #002 | Эхо в Логах | `grep`, `awk`, `sed`, пайпы `\|` | ~20 мин |
| #003 | Мёртвый Страж | чтение логов, диагностика сервисов, `mv` | ~25 мин |
| #004 | Ночной Таймер | `find -mtime`, `cat`, `sed`, cron | ~25 мин |
| #005 | Протокол Феникс | всё вместе + `tar` | ~45 мин |

## Сезон 2: Операция Автоматизация

> Kira-7 внедряется в корпорацию OmegaTech. Каждое дело — этап тайной операции.

| Дело | Название | Навыки | Время |
|------|----------|--------|-------|
| #101 | Первый Контакт | `set -euo pipefail`, переменные, `if/else` | ~20 мин |
| #102 | Сборочный Цех | функции, `for`-цикл, обработка файлов | ~25 мин |
| #103 | Ночной Сторож | `crontab`, `PATH` в cron, `flock`, логирование | ~25 мин |
| #104 | Постоянный Дозор | `systemd` unit + timer, `Persistent=true` | ~30 мин |
| #105 | Финал: Исход | `ssh-keygen`, `authorized_keys`, `rsync` | ~40 мин |

Запуск Сезона 2:
```bash

```

## Как играть

Каждое дело состоит из двух шагов:

**1. Развернуть среду**
```bash
bash ~/nexus7/setup_caseN.sh
```
Скрипт создаёт "поломанный" сервер и выводит брифинг с заданием.

**2. Расследовать и решить**

Работай в папке `~/nexus7/caseN/`, используй подсказки из брифинга.

**3. Проверить решение**
```bash
bash ~/nexus7/check_caseN.sh
```
Скрипт проверяет условия и говорит что не так, если ошибся.

> Setup можно запускать повторно — среда пересоздаётся с нуля.
