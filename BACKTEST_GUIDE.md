# Гайд по бэктесту TSLA ORB EA
## Брокер: Capital.com | Netting | ContractSize=1 | Сервер UTC+0

---

## 1. Подготовка истории котировок

Перед первым бэктестом нужно скачать историю тиков TSLA.

1. В MT5: **Сервис → Котировки** (или `Ctrl+U`)
2. Найти **TSLA** в списке
3. Правая кнопка → **Загрузить** — ждёшь пока прогресс не дойдёт до 100%
4. Повторить для таймфрейма **M5** (дважды кликни на TSLA → M5 → Скачать)

> Без полной истории тиков бэктест будет неточным — ORB-свеча может не найтись.

---

## 2. Открытие Strategy Tester

**Вид → Strategy Tester** (или `Ctrl+R`)

---

## 3. Настройки бэктеста

### Вкладка "Настройки"

| Поле | Значение | Комментарий |
|---|---|---|
| **Expert Advisor** | TSLA_ORB_v1 | Выбрать из списка |
| **Символ** | TSLA | Как на Capital.com |
| **Таймфрейм** | M5 | EA читает M5-свечи |
| **Модель** | Every tick based on real ticks | Максимальная точность |
| **Депозит** | твой реальный баланс | Лот считается от баланса |
| **Валюта** | USD | |
| **Кредитное плечо** | 1:20 | Capital.com CFD на акции |

### Модель качества данных

```
Every tick based on real ticks  ← использовать всегда
Every tick                      ← если нет реальных тиков (хуже)
OHLC on M1                      ← только для быстрой проверки логики
```

## 4. Периоды для тестирования (из ТЗ v2.1)

Запускай два отдельных теста — летний и зимний, с разным ETOffset.

### Летний (EDT, UTC-4)

| Поле | Значение |
|---|---|
| Дата с | 10.03.2025 |
| Дата по | 31.10.2025 |
| ETOffset | **-4** |
| AutoDST | false |

### Зимний (EST, UTC-5)

| Поле | Значение |
|---|---|
| Дата с | 04.11.2024 |
| Дата по | 08.03.2025 |
| ETOffset | **-5** |
| AutoDST | false |

> В бэктесте выставляй `AutoDST=false` и вручную выставляй ETOffset под период.
> `AutoDST=true` работает корректно только на живом счёте.

Нажми **Параметры** и выставь:

```
Symbol               = TSLA
Leverage             = 20.0
EntryOffset          = 0.50
TakeProfit           = 6.00
BreakevenThreshold   = 1.50
MaxSlippage          = 30
RetryDelay           = 500

AutoDST              = false     ← в бэктесте выключить
MaxDailyLossPercent  = 2.0
MaxDrawdownPercent   = 0.0
TradingRatio         = 0.7143
MaxLossPercent       = 28.5
StartBalance         = 0.0       ← авто
SpikeFilterThreshold = 2.00
BasePrice            = 400.00    ← средняя цена TSLA за период теста
UseDynamicParams     = true
Magic                = 20250101
EnablePush           = false     ← отключить в бэктесте
EnableEmail          = false
EnableSound          = false
LogLevel             = INFO
```

## 6. Запуск и индикаторы качества

Нажми **Старт**. После завершения:

### Вкладка "Результаты" — что смотреть

| Метрика | Хорошо | Плохо |
|---|---|---|
| Profit Factor | > 1.5 | < 1.0 |
| Ожидаемый выигрыш | > 0 | < 0 |
| Просадка (макс.) | < 20% | > 30% |
| Всего сделок | > 20 | < 10 |
| % прибыльных | > 40% | < 30% |

### Вкладка "График" — что смотреть

- Equity curve (синяя) — должна расти плавно
- Резкие просадки — сигнал проблемы с параметрами
- Flat периоды — нет входов (проверь ETOffset)

## 7. Как сохранить логи

### Способ 1 — из интерфейса (рекомендуется)

1. После бэктеста → вкладка **Журнал (Journal)**
2. Правая кнопка мыши в любом месте журнала
3. **Сохранить как...** → выбери папку → сохрани `.log` файл

### Способ 2 — найти файл напрямую

```
MT5 → Файл → Открыть папку данных →
папка MQL5 → Logs → Tester → YYYY-MM-DD.log
```

## 8. Частые проблемы в бэктесте

### Нет сделок вообще
- Проверь **ETOffset** — возможно неправильное время ORB-свечи
- В журнале ищи: `Свеча ORB 09:25 ET не найдена` — нет истории тиков
- Перескачай историю TSLA

### Все дни — STATE_DISABLED_TODAY
- `ETOffset` не соответствует периоду (лето/зима)
- Проверь лог: `EA запущен после окна входа` — EA запускается не в то время

### Лот = 0 или ошибка объёма
- В логе будет: `g_lotSize=0 — цена ORB свечи недоступна`
- Причина: нет данных iClose для M5-свечи
- Решение: скачай больше истории

### Лот = 1 (минимум) при любом балансе
- `BasePrice` сильно отличается от реальной цены TSLA в периоде
- Выставь `BasePrice` ≈ средней цене TSLA за период теста
- Capital.com MinLot=1, шаг=1 — лот всегда целое число акций

### Ошибка "Netting счёт не найден" (INIT_FAILED)
- Убедись что открыт счёт Capital.com, а не Exness или другой брокер
- В заголовке MT5 должно быть видно Capital.com

### Нет сделок после 10:00 ET
- Это норма — окно входа только 09:30–10:00 ET

## 9. Рекомендуемый порядок тестирования

```
1. Быстрая проверка логики    → OHLC on M1, 1 месяц
2. Точный тест                → Real ticks, летний период
3. Точный тест                → Real ticks, зимний период
4. Оптимизация параметров     → встроенный оптимизатор MT5
```

### Параметры для оптимизации (в порядке приоритета)

| Параметр | Диапазон | Шаг |
|---|---|---|
| `EntryOffset` | 0.25 – 1.00 | 0.25 |
| `TakeProfit` | 3.00 – 10.00 | 1.00 |
| `BreakevenThreshold` | 0.50 – 3.00 | 0.50 |
| `Leverage` | 10 – 30 | 5 |
