Бэктест для проверки летнего и зимнего часового пояса

 Всё делается прямо в MT5, никакой сервер не нужен.
  
  Шаги

  1. Открыть демо-счёт на Exness
  - Зайди на exness.com → Личный кабинет
  - "Открыть счёт" → Демо → MT5 → Hedging (важно — именно Hedging, EA проверяет это при запуске)
  - Начальный баланс поставь близкий к тому с которого планируешь торговать live

  2. Подключиться к демо в MT5
  - Файл → Войти в торговый счёт
  - Введи номер демо-счёта и пароль
  - Сервер выбирай Exness — тот же что и для реального счёта

  3. Скопировать файлы EA на компьютер
  В MT5: Файл → Открыть папку данных → MQL5/Experts/
  Скопируй туда:
  TSLA_ORB_v1.mq5
  Levels.mqh
  Risk.mqh
  Entry.mqh
  Position.mqh
  Logger.mqh

  4. Скомпилировать
  - Открой TSLA_ORB_v1.mq5 в MetaEditor (F4 из MT5)
  - Нажми Compile (F7)
  - Внизу должно быть 0 error(s), 0 warning(s)
  - Если есть ошибки — стоп, сначала разбираемся

  5. Найти символ TSLA на Exness
  - В MT5: Вид → Обзор рынка (Ctrl+M)
  - Поищи TSLA — скорее всего будет с суффиксом, например TSLA или #TSLA
  - Точное имя символа нужно вписать в параметр InpSymbol при запуске EA

  6. Запустить EA на график
  - Открой график TSLA (или как называется на Exness), таймфрейм M1
  - Перетащи EA из Navigator → Expert Advisors на график
  - В настройках выставь параметры (особенно InpSymbol — точное имя символа)
  - Убедись что кнопка "Авто-торговля" активна (зелёная вверху MT5)

  7. Проверь что работает
  На следующий торговый день в 13:30 или 14:30 UTC (в зависимости от DST) в логе должна появиться строка:
  Risk.mqh
  Entry.mqh
  Risk.mqh
  Entry.mqh
  Position.mqh
  Logger.mqh

  Если этой строки нет — что-то не так с символом или временем.

  ---
  Главное: MT5 должен быть открыт и подключён всё торговое время. Если закроешь — EA не работает. Для надёжности можно арендовать VPS (Exness
  даёт бесплатный VPS при определённом обороте), но для первых 2–3 недель демо хватит и с домашнего компьютера.
