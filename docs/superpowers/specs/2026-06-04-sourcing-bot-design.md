# Sourcing Bot — Design Spec
**Date:** 2026-06-04  
**Status:** Approved

## Overview

Telegram-бот для поиска и сравнения поставщиков товаров из Китая (Alibaba + 1688.com). Бот автоматически скрапит площадки, анализирует результаты через Claude AI, сравнивает поставщиков по полному набору критериев и помогает пользователю выйти на контакт.

---

## Категории товаров

**Встроенные категории с подкатегориями:**

- **Массажное оборудование:** массажное кресло, пистолет-массажер, массажный стол, массажная подушка, ручной массажер
- **Фильтры воды:** фильтр обратного осмоса, проточный фильтр, кувшин-фильтр, ультрафиолетовый фильтр
- **Фильтры воздуха:** HEPA очиститель, угольный фильтр, ионизатор, промышленный фильтр

Пользователь может добавлять новые категории и подкатегории через `/add_category`.

## UX-поток

### Основной поиск
1. `/categories` → выбор категории (кнопки)
2. Выбор подкатегории (кнопки) или "Все сразу"
3. Бот скрапит Alibaba + 1688 (топ 15 с каждой = 30 позиций)
4. Claude анализирует, ранжирует, возвращает топ-5
5. Каждый результат: цена, MOQ, рейтинг, годы на платформе, доставка, сертификаты
6. Кнопки: `[📞 Контакты]` `[💾 Сохранить]` `[📊 Полное сравнение]`

### Свободный поиск
- `/search <запрос>` — поиск любого товара без привязки к категории

### Результат
```
1. Shenzhen MassagePro Co.
   💰 $12–18/шт  |  MOQ: 50 шт
   ⭐ 4.8  |  📦 8 лет на платформе
   🚚 14–21 дней  |  ✅ CE, RoHS
   ⚠️ Красные флаги: нет
   [📞 Контакты]  [💾 Сохранить]
```

## Критерии сравнения

Claude анализирует каждого поставщика по:
- Цена (диапазон мин/макс)
- MOQ (минимальный заказ)
- Рейтинг поставщика на платформе
- Количество отзывов
- Лет на платформе
- Срок доставки
- Наличие сертификатов (CE, ISO, RoHS и др.)
- Фото товара (наличие)
- Отклонение цены от средней по рынку

---

## Красные флаги (автоматически)

Claude помечает ⚠️ если:
- Поставщик зарегистрирован менее 1 года назад
- Менее 5 отзывов
- Цена более чем на 40% ниже средней по рынку
- Нет фотографий товара
- Нет сертификатов для товаров где они обязательны

## Функции

### Шаблоны переговоров
Команда `[📝 Шаблон]` → Claude генерирует сообщение на английском:
- Запрос цены на объём
- Просьба снизить MOQ
- Запрос образца (sample)
Пользователь копирует и отправляет сам.

### Еженедельный мониторинг цен
- APScheduler запускает ре-скрапинг сохранённых поставщиков каждое воскресенье в 09:00
- Если цена изменилась >5% — уведомление в Telegram

### Калькулятор landed cost
- Пользователь вводит: количество единиц
- Бот считает: цена × кол-во + доставка (оценка по весу) + таможня (~10-20% для КЗ/РУ)
- Итог: стоимость единицы с доставкой

### Избранное со статусами
Статусы: `Найден` → `Контактирую` → `Жду ответа` → `Заказал` / `Отказал`  
Команда `/favorites` — список с фильтром по статусу.

### История поисков
Последние 20 поисков сохраняются. Команда `/history` — повторить поиск одним нажатием.

| Компонент | Технология |
|-----------|-----------|

## База данных (модели)

**Supplier** — поставщик из результатов скрапинга  
`id, platform, name, price_min, price_max, moq, rating, reviews, years_on_platform, delivery_days, certifications, contacts, url, scraped_at`

**Search** — история поисков  
`id, user_id, query, category, subcategory, results_json, created_at`

**Favorite** — избранные поставщики  
`id, user_id, supplier_id, status, notes, created_at, updated_at`

## Ограничения и риски

- **Блокировки скрапинга:** Alibaba и 1688 могут блокировать. Решение: `playwright-stealth`, случайные задержки, ротация user-agent. При серьёзных блокировках — подключить прокси (Bright Data / Oxylabs).
- **Скорость:** Скрапинг 30 позиций + AI анализ занимает ~30–60 секунд. Бот показывает прогресс (`🔍 Ищу...`).
- **1688 на китайском:** `deep-translator` переводит бесплатно, но качество перевода технических характеристик может быть неточным.
